# 🚀 Discord Rich Presence – Status Lucu Anak Kerja

Tampilkan status kerja lucu dan kekinian di profil Discord kamu!  
Proyek ini menggunakan **Discord RPC (Rich Presence)** untuk membuat status kustom seperti:

> “Meeting online, pikiran offline”  
> “Ngopi sambil kerja remote ☕”

---

![contoh](https://github.com/J13PhantomByte/discord-rich-presence/blob/juan/contoh.png) 

---

## ✨ Fitur

- Status kerja lucu, kekinian, dan bisa diedit sendiri
- Bisa tampilkan gambar besar + teks deskripsi
- Integrasi penuh dengan [Discord Developer Portal](https://discord.com/developers)

---

## 🧰 Persyaratan

- Node.js (disarankan versi terbaru)
- Akun Discord
- Aplikasi Discord Developer (gratis)
- Discord desktop **harus terbuka** saat menjalankan script
